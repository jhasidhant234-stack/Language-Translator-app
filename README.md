# Language Translator App 🌐

A desktop-based language translation application developed using **Python, Tkinter, and Googletrans**. The application provides a simple graphical interface for translating text between multiple languages.

## Features

- 🌐 Translate text between multiple languages
- 🔍 Automatic source-language detection
- 🎯 Specify source and target languages
- 🖥️ User-friendly Tkinter GUI
- ⚡ Asynchronous translation using `asyncio`
- 🧹 Clear input fields with one click
- ⚠️ Error handling for invalid input and language codes

## Technologies Used

- Python 3.12
- Tkinter
- Googletrans
- Asyncio

## How It Works

1. Enter the text you want to translate.
2. Enter the source language code, or leave it empty for automatic detection.
3. Enter the target language code.
4. Click **Translate**.
5. The translated text will be displayed in a pop-up window.

### Example

```text
Text: Hello, how are you?
Source: en
Target: fr

Result: Bonjour, comment allez-vous ?
